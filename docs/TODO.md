# TODO – Game Boy Emulator (Rust) Development Plan
目標：1.5ヶ月で「テトリスが正常に動作する Game Boy エミュレータ」を完成させる  
     GBエミュレータを通したRustと低レイヤー動作の理解
方針：後から実機レベルのPPU等を追加できるよう、拡張しやすい設計を維持する

---

## 全体方針
- 機能単位で確実に動作させていく
- CPU と PPU（Controller + BG描画）に重点を置く
- PPU の内部色表現は実機に合わせて **0〜3（2bit）**
- PPU は **Controller / Renderer / FrameBuffer** の 3 層に分割
- 最低限の機能でテトリスが動く状態を目指す
