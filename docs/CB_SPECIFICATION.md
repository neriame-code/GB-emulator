# CB-PREFIX INSTRUCTION SPECIFICATION

> 0xCB を読んだ時点で「次のバイトを別テーブルで引く」2段階デコードが必要。  
> 全命令共通で **8サイクル（レジスタ対象）** または **16サイクル（(HL)対象）**。  
> フラグ表記: `*` = 結果に応じてセット/リセット、`0` = 常に0、`1` = 常に1、`-` = 変化なし

---

## RLC（左ローテート、bit7 → C かつ bit0）

> ビット列を左に1回転させる。MSB（bit7）が Carry フラグとbit0の両方に入る。

| CB Opcode | Mnemonic    | 処理                                    | Cycles | Z | N | H | C |
|-----------|-------------|-----------------------------------------|--------|---|---|---|---|
| 0x00      | RLC B       | B ← (B << 1) \| (B >> 7); C ← B[7]    | 8      | * | 0 | 0 | * |
| 0x01      | RLC C       | C ← (C << 1) \| (C >> 7); C ← C[7]    | 8      | * | 0 | 0 | * |
| 0x02      | RLC D       | D ← (D << 1) \| (D >> 7); C ← D[7]    | 8      | * | 0 | 0 | * |
| 0x03      | RLC E       | E ← (E << 1) \| (E >> 7); C ← E[7]    | 8      | * | 0 | 0 | * |
| 0x04      | RLC H       | H ← (H << 1) \| (H >> 7); C ← H[7]    | 8      | * | 0 | 0 | * |
| 0x05      | RLC L       | L ← (L << 1) \| (L >> 7); C ← L[7]    | 8      | * | 0 | 0 | * |
| 0x06      | RLC (HL)    | mem[HL] ← (mem[HL] << 1) \| (mem[HL] >> 7); C ← mem[HL][7] | 16 | * | 0 | 0 | * |
| 0x07      | RLC A       | A ← (A << 1) \| (A >> 7); C ← A[7]    | 8      | * | 0 | 0 | * |

---

## RRC（右ローテート、bit0 → C かつ bit7）

> ビット列を右に1回転させる。LSB（bit0）が Carry フラグとbit7の両方に入る。

| CB Opcode | Mnemonic    | 処理                                    | Cycles | Z | N | H | C |
|-----------|-------------|-----------------------------------------|--------|---|---|---|---|
| 0x08      | RRC B       | B ← (B >> 1) \| (B << 7); C ← B[0]    | 8      | * | 0 | 0 | * |
| 0x09      | RRC C       | C ← (C >> 1) \| (C << 7); C ← C[0]    | 8      | * | 0 | 0 | * |
| 0x0A      | RRC D       | D ← (D >> 1) \| (D << 7); C ← D[0]    | 8      | * | 0 | 0 | * |
| 0x0B      | RRC E       | E ← (E >> 1) \| (E << 7); C ← E[0]    | 8      | * | 0 | 0 | * |
| 0x0C      | RRC H       | H ← (H >> 1) \| (H << 7); C ← H[0]    | 8      | * | 0 | 0 | * |
| 0x0D      | RRC L       | L ← (L >> 1) \| (L << 7); C ← L[0]    | 8      | * | 0 | 0 | * |
| 0x0E      | RRC (HL)    | mem[HL] ← (mem[HL] >> 1) \| (mem[HL] << 7); C ← mem[HL][0] | 16 | * | 0 | 0 | * |
| 0x0F      | RRC A       | A ← (A >> 1) \| (A << 7); C ← A[0]    | 8      | * | 0 | 0 | * |

## RL（左ローテート、Carry 経由）

> ビット列を左に1シフトし、旧 Carry が bit0 に入る。bit7 が新 Carry になる。  
> RLC との違い: Carry を「経由地」として使うため、9ビットのローテートになる。

| CB Opcode | Mnemonic    | 処理                                    | Cycles | Z | N | H | C |
|-----------|-------------|-----------------------------------------|--------|---|---|---|---|
| 0x10      | RL B        | B ← (B << 1) \| old_C; C ← B[7]       | 8      | * | 0 | 0 | * |
| 0x11      | RL C        | C ← (C << 1) \| old_C; C ← C[7]       | 8      | * | 0 | 0 | * |
| 0x12      | RL D        | D ← (D << 1) \| old_C; C ← D[7]       | 8      | * | 0 | 0 | * |
| 0x13      | RL E        | E ← (E << 1) \| old_C; C ← E[7]       | 8      | * | 0 | 0 | * |
| 0x14      | RL H        | H ← (H << 1) \| old_C; C ← H[7]       | 8      | * | 0 | 0 | * |
| 0x15      | RL L        | L ← (L << 1) \| old_C; C ← L[7]       | 8      | * | 0 | 0 | * |
| 0x16      | RL (HL)     | mem[HL] ← (mem[HL] << 1) \| old_C; C ← mem[HL][7] | 16 | * | 0 | 0 | * |
| 0x17      | RL A        | A ← (A << 1) \| old_C; C ← A[7]       | 8      | * | 0 | 0 | * |

---

## SLA（算術左シフト）

> ビット列を左に1シフト。bit0 は必ず 0 になる。bit7 が Carry に入る。  
> 符号なし整数の ×2 に相当する（オーバーフローは Carry で検出）。

| CB Opcode | Mnemonic    | 処理                        | Cycles | Z | N | H | C |
|-----------|--------------|-----------------------------|--------|---|---|---|---|
| 0x20      | SLA B        | C ← B[7]; B ← B << 1       | 8      | * | 0 | 0 | * |
| 0x21      | SLA C        | C ← C[7]; C ← C << 1       | 8      | * | 0 | 0 | * |
| 0x22      | SLA D        | C ← D[7]; D ← D << 1       | 8      | * | 0 | 0 | * |
| 0x23      | SLA E        | C ← E[7]; E ← E << 1       | 8      | * | 0 | 0 | * |
| 0x24      | SLA H        | C ← H[7]; H ← H << 1       | 8      | * | 0 | 0 | * |
| 0x25      | SLA L        | C ← L[7]; L ← L << 1       | 8      | * | 0 | 0 | * |
| 0x26      | SLA (HL)     | C ← mem[HL][7]; mem[HL] ← mem[HL] << 1 | 16 | * | 0 | 0 | * |
| 0x27      | SLA A        | C ← A[7]; A ← A << 1       | 8      | * | 0 | 0 | * |

---

## SRA（算術右シフト）

> ビット列を右に1シフト。bit7（符号ビット）は変化しない（符号拡張）。bit0 が Carry に入る。  
> 符号付き整数の ÷2 に相当する。

| CB Opcode | Mnemonic    | 処理                                   | Cycles | Z | N | H | C |
|-----------|-------------|----------------------------------------|--------|---|---|---|---|
| 0x28      | SRA B       | C ← B[0]; B ← (B & 0x80) \| (B >> 1) | 8      | * | 0 | 0 | * |
| 0x29      | SRA C       | C ← C[0]; C ← (C & 0x80) \| (C >> 1) | 8      | * | 0 | 0 | * |
| 0x2A      | SRA D       | C ← D[0]; D ← (D & 0x80) \| (D >> 1) | 8      | * | 0 | 0 | * |
| 0x2B      | SRA E       | C ← E[0]; E ← (E & 0x80) \| (E >> 1) | 8      | * | 0 | 0 | * |
| 0x2C      | SRA H       | C ← H[0]; H ← (H & 0x80) \| (H >> 1) | 8      | * | 0 | 0 | * |
| 0x2D      | SRA L       | C ← L[0]; L ← (L & 0x80) \| (L >> 1) | 8      | * | 0 | 0 | * |
| 0x2E      | SRA (HL)    | C ← mem[HL][0]; mem[HL] ← (mem[HL] & 0x80) \| (mem[HL] >> 1) | 16 | * | 0 | 0 | * |
| 0x2F      | SRA A       | C ← A[0]; A ← (A & 0x80) \| (A >> 1) | 8      | * | 0 | 0 | * |

## SWAP（上位4bitと下位4bitを交換）

> ニブル単位の交換。Carry を含む全フラグがリセットされる点に注意。

| 0x30      | SWAP B      | B ← (B << 4) \| (B >> 4)               | 8      | * | 0 | 0 | 0 |
| 0x31      | SWAP C      | C ← (C << 4) \| (C >> 4)               | 8      | * | 0 | 0 | 0 |
| 0x32      | SWAP D      | D ← (D << 4) \| (D >> 4)               | 8      | * | 0 | 0 | 0 |
| 0x33      | SWAP E      | E ← (E << 4) \| (E >> 4)               | 8      | * | 0 | 0 | 0 |
| 0x34      | SWAP H      | H ← (H << 4) \| (H >> 4)               | 8      | * | 0 | 0 | 0 |
| 0x35      | SWAP L      | L ← (L << 4) \| (L >> 4)               | 8      | * | 0 | 0 | 0 |
| 0x36      | SWAP (HL)   | mem[HL] ← (mem[HL] << 4) \| (mem[HL] >> 4) | 16 | * | 0 | 0 | 0 |
| 0x37      | SWAP A      | A ← (A << 4) \| (A >> 4)               | 8      | * | 0 | 0 | 0 |

## SRL（論理右シフト）

> ビット列を右に1シフト。bit7 は必ず 0 になる（符号拡張なし）。bit0 が Carry に入る。  
> SRA との違い: bit7 が 0 で埋まるため、符号なし整数の ÷2 に相当する。

| 0x39      | SRL C       | C ← C[0]; C ← C >> 1       | 8      | * | 0 | 0 | * |
| 0x3A      | SRL D       | C ← D[0]; D ← D >> 1       | 8      | * | 0 | 0 | * |
| 0x3B      | SRL E       | C ← E[0]; E ← E >> 1       | 8      | * | 0 | 0 | * |
| 0x3C      | SRL H       | C ← H[0]; H ← H >> 1       | 8      | * | 0 | 0 | * |
| 0x3D      | SRL L       | C ← L[0]; L ← L >> 1       | 8      | * | 0 | 0 | * |
| 0x3E      | SRL (HL)    | C ← mem[HL][0]; mem[HL] ← mem[HL] >> 1 | 16 | * | 0 | 0 | * |
| 0x3F      | SRL A       | C ← A[0]; A ← A >> 1       | 8      | * | 0 | 0 | * |

## 実装上の注意点

**2段階デコード**  
通常の命令フェッチで0xCBを読んだ場合、PCをインクリメントした後さらに1バイトフェッチし、そのバイトをCBテーブルで引く。命令テーブルはnormalとcbの2つを分けて管理する

**BIT 命令のサイクル数**  
BIT n, (HL)はPanDocsでは12サイクル。RES/SETの(HL)変種は16サイクル。BITだけ異なるので注意

**RLCA / RRCA / RLA / RRA との違い**  
0x07(RLCA)などのnon-CB版はZフラグを常に0にリセットする。CB版のRLC A/RR Aは結果が0ならZフラグをセットする。挙動が異なるため、実装時に混同しないこと

**old_C の取得タイミング**  
RL/RR系では、シフト処理の前にCarryフラグの現在値を保存しておく必要がある。シフト後にCフラグを更新してからbit0/bit7に旧Carryを入れると値が壊れる
