# OPCODE SPECIFICATION

> フラグ表記: `*` = 結果に応じてセット/リセット、`0` = 常に0、`1` = 常に1、`-` = 変化なし

> フラグ更新について
- HフラグとCフラグは「この演算で繰り上がり・借り下がりが発生したか」を判定するため、演算前の値から計算
- Zフラグは「演算結果が0か」を判定するため、更新した結果を見る
